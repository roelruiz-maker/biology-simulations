Understand the wet-lab setup before you run it

This screen explains what the simulated apparatus represents. It does not tell you which wavelength should produce the fastest reaction.
DCPIPA blue redox indicator. It becomes colourless when reduced. The endpoint is judged by comparison with tube 8.
Coloured light filterA transparent coloured sleeve around a tube. It changes the wavelengths reaching the chloroplast suspension. It is not the muslin used to filter leaf extract.
Aluminium foilBlocks light completely around tube 7 to create the dark control.
Chloroplast suspensionIn the wet lab, fresh spinach is homogenised in ice-cold isolation medium and filtered through muslin to obtain the extract.
Tube 8: distilled waterA colourless comparison. It contains no DCPIP and helps you judge when a DCPIP tube has lost its blue colour.
Constant setupThe wet-lab method uses 5 cm³ DCPIP, 1 cm³ chloroplast suspension and a 10 cm distance from the lamp for each reaction tube.

How this run works: select Start exposure. Record each tube when it becomes colourless. Do not wait for 900 s if it has already reached its endpoint. Only tubes still blue at 900 s are recorded as “no change”.
